## Acessos por papel

| Papel | Acessos adicionais |
|-------|--------------------|
| Desenvolvimento | GitHub (organização), registro de imagens, ambientes de dev/staging |
| Dados | Data warehouse (leitura), ferramenta de BI |
| Infraestrutura | Console de cloud (leitura), ferramenta de observabilidade |

## Regras

- Acesso segue o **menor privilégio**: peça só o que precisa para a tarefa.
- Acesso a produção é temporário e auditado.
- Credenciais são pessoais e intransferíveis.
- Ao mudar de time, os acessos antigos são revisados.
