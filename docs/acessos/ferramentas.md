# Ferramentas

| Categoria | Ferramenta | Observação |
|-----------|------------|------------|
| Código | Git + GitHub | Commits assinados recomendados |
| Editor | VS Code | Extensões aprovadas pelo time |
| Containers | Podman / Podman Desktop | Sem Docker Desktop |
| Portal | Backstage | Catálogo, docs e templates |
| Comunicação | Chat e e-mail corporativos | Veja [Comunicação](../praticas/comunicacao.md) |
| Chamados | Portal de chamados de TI | Acessos, equipamento, incidentes |

## Instalação

Instale ferramentas pelo catálogo de software corporativo quando disponível. Ferramentas fora
do catálogo precisam de aprovação (veja [Segurança da informação](../praticas/seguranca-da-informacao.md)).
