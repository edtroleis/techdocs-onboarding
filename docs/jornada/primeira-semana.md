# Primeira semana

## Objetivos

1. Ambiente de trabalho completo (veja [Estação de trabalho](../acessos/estacao-de-trabalho.md)).
2. Entender o fluxo do time, da demanda ao deploy (veja [Fluxo de trabalho](../praticas/fluxo-de-trabalho.md)).
3. Concluir uma primeira tarefa pequena, com revisão e entrega.

## Sugestão de agenda

| Dia | Foco |
|-----|------|
| 1–2 | Acessos, equipamento e apresentações |
| 3 | Ferramentas e repositórios do time; leitura das docs no Backstage |
| 4 | Pareamento com o buddy numa tarefa real |
| 5 | Primeira entrega pequena; retrospectiva da semana com a pessoa gestora |
