# Comunicação

## Onde falar o quê

| Assunto | Canal |
|---------|-------|
| Dúvida rápida do time | Canal do time no chat |
| Decisão que precisa de registro | Documento ou ADR, com link no chat |
| Incidente em produção | Canal de incidentes |
| Pedido de acesso ou equipamento | Portal de chamados |
| Assunto pessoal ou sensível | Conversa direta com a pessoa gestora |

## Boas práticas

- Prefira canais abertos a mensagens diretas: a resposta ajuda outras pessoas.
- Escreva a pergunta completa na primeira mensagem (contexto, o que tentou, erro).
- Decisões importantes viram documentação, não ficam só no chat.
