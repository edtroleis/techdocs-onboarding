# Contatos e canais

| Precisa de | Quem procurar |
|------------|---------------|
| Dúvidas do dia a dia | Buddy de onboarding |
| Prioridades, metas, férias | Pessoa gestora |
| Acessos e equipamento | Suporte de TI (portal de chamados) |
| Plataforma, CI/CD, Backstage | `platform-team` |
| Segurança da informação | Time de segurança (canal de incidentes) |
| Privacidade e dados pessoais | Encarregado de dados (DPO) |

No Backstage, a página de cada **Group** do catálogo mostra membros e componentes do time.
