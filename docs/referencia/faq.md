# FAQ

??? question "Meu acesso ainda não foi liberado. O que faço?"
    Confira o status no portal de chamados. Passou do prazo típico (veja
    [Contas e acessos](../acessos/contas-e-acessos.md))? Avise a pessoa gestora.

??? question "Posso instalar qualquer ferramenta no meu equipamento?"
    Não. Use o catálogo de software corporativo; fora dele, peça aprovação.

??? question "Onde encontro a documentação dos sistemas?"
    No Backstage: menu **Docs** → **All Docs**, ou na aba **Docs** de cada componente.

??? question "Como sugiro uma melhoria neste guia?"
    Use o ícone de edição no topo da página para abrir um PR no repositório.
