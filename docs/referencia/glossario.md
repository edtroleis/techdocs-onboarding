# Glossário

Buddy
:   Pessoa do time que acompanha você nas primeiras semanas.

Backstage
:   Portal interno com o catálogo de software, documentação (TechDocs) e templates.

Golden path
:   Caminho recomendado e suportado para construir e operar software.

MFA
:   Autenticação multifator: senha + um segundo fator (app, token).

Runbook
:   Documento com os passos para operar um serviço e responder a alertas.

WSL
:   Windows Subsystem for Linux: ambiente Linux dentro do Windows.
